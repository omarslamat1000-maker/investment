# قاموس البيانات

قاعدة IndexedDB: `madinah-initiatives-platform-db` — الإصدار 1 — المفتاح الرئيس دائمًا `id`.
كل السجلات تحمل `createdAt` و`updatedAt` (ISO 8601) تُدار في `js/data/repositories.js`.

## initiatives — المبادرات
| الحقل | النوع | الوصف |
|---|---|---|
| id | text | `MDN-INIT-YYYY-NNNN` |
| title / summary / scope | text | الاسم، الوصف، نطاق العمل |
| category | text | معرف من `CATEGORIES` (greening، lighting، …) |
| district | text | من قائمة `DISTRICTS` |
| location, lat, lng | text/number | الموقع الوصفي والإحداثيات |
| status | text | من `STATUSES` — انظر دورة الحياة |
| channel | text | internal / public / partner |
| submitterName/Entity/Email/Phone | text | بيانات مقدّم المبادرة |
| budget / spent | number | بالريال |
| fundingModel | text | من `PARTNERSHIP_MODELS` |
| startDate / endDate | date | YYYY-MM-DD |
| orgUnitId / ownerName | text | الوحدة المشرفة ومالك المبادرة |
| scores | object | `{strategic, impact, feasibility, readiness, risk}` كل منها 1–5 |
| beneficiaries | number | المستفيدون المقدَّرون |
| statusHistory | array | `[{from, to, at, by, decisionId}]` |

## infrastructureNeeds — الاحتياجات
`id` بصيغة `MDN-NEED-…`، `status`: draft/published/matched/closed،
`priority`: low/medium/high، `estimatedCost`، `expectedImpact`،
`preferredModels[]`، `publishedAt`، `matchedInitiativeId` (مرجع مبادرة).

## partners — الشركاء
`id` بصيغة `MDN-PRT-…`، `type`: private/nonprofit/gov/community،
`crNumber`، بيانات ممثل الجهة، `interests[]` (تصنيفات)، `models[]` (نماذج شراكة)،
`rating` (1–5 بعد التنفيذ)، `active`.

## initiativePartners — روابط الشراكة
`initiativeId`، `partnerId`، `model`، `contribution`، `signedAt`.

## decisions — قرارات البوابات
`id` بصيغة `MDN-DEC-…`، `initiativeId`، `gateId` (G0–G4)،
`outcome`: pass/reject/hold، `at`، `by`، `rationale` (إلزامي).

## gateChecklists — قوائم تحقق البوابات
`initiativeId`، `gateId`، `items[]`: `{key, text, done, note}`.

## reviews — مراجعات اللجنة
`initiativeId`، `gateId`، `reviewer`، `at`، `recommendation`، `notes`.

## benefits — المنافع
`initiativeId`، `title`، `unit`، `baseline`، `target`، `actual` (null = لم تُقس)،
`measuredAt`، `owner`. نسبة التحقق تُشتق ولا تُخزن.

## risks — المخاطر
`initiativeId`، `title`، `probability` (1–4)، `impact` (1–4)،
`response`، `owner`، `status`: open/mitigated/closed. التعرض يُشتق (ض×أ).

## milestones — المعالم
`initiativeId`، `title`، `due`، `done`، `doneAt`.

## qualityChecks — فحوص الجودة
`initiativeId`، `title`، `at`، `result`: pass/fail، `inspector`، `notes`.

## kpis — مؤشرات المنصة
`initiativeId` (null = مستوى المنصة)، `title`، `unit`، `target`، `actual`، `period`.

## بقية المخازن
- **campaigns**: حملات موسمية `{title, summary, startDate, endDate, targetInitiatives, categoryFocus[], status}`.
- **deliverables**: مخرجات مستلمة `{initiativeId, title, accepted, acceptedAt}`.
- **changeRequests**: طلبات تغيير `{initiativeId, title, description, status, decision}`.
- **comments**: تعليقات `{initiativeId, author, body, at}`.
- **attachments**: مرفقات Base64 بحد 2MB `{initiativeId, name, type, size, dataUrl}`.
- **users / organizationalUnits**: مستخدمو العرض والوحدات التنظيمية.
- **notifications**: `{title, body, level, at, read}`.
- **auditLogs**: `{at, actor, role, action, store, recordId, note}`.
- **settings**: إعدادات وعلم البذور `seed-status`.
- **savedViews**: عروض محفوظة (مهيأة للاستخدام المستقبلي).

## الفهارس
- initiatives: status، category، district
- infrastructureNeeds: status، district
- auditLogs/notifications: at
- كل المخازن المرتبطة بمبادرة: فهرس `initiativeId`
