# دليل الحوكمة — البوابات المرحلية وإدارة المنافع

## النموذج المرجعي
تجمع المنصة بين ثلاث ممارسات معتمدة دوليًا:
- **Stage-Gate**: قرار صريح مُسبَّب عند كل انتقال جوهري.
- **إدارة المنافع (BRM)**: كل مبادرة معتمدة لها منافع مستهدفة قابلة للقياس، تُقاس وتُعلن.
- **إدارة محافظ المبادرات**: مفاضلة موزونة وموارد وقرارات على مستوى المحفظة.

## البوابات الخمس

| البوابة | من ← إلى | ما يُفحص | القرار الممكن |
|---|---|---|---|
| **G0 الفرز** | قيد الفرز ← قيد الدراسة | اكتمال الطلب، الاختصاص، عدم التعارض | اجتياز / اعتذار |
| **G1 الجدوى** | قيد الدراسة ← قيد الاعتماد | دراسة فنية ومجتمعية + درجات المفاضلة | اجتياز / اعتذار |
| **G2 الاعتماد** | قيد الاعتماد ← الجاهزية | اعتماد اللجنة، اتفاقية الشراكة، المنافع المستهدفة | اجتياز / تعليق |
| **G3 الجاهزية** | الجاهزية ← التنفيذ | الخطة، التصاريح، الموقع، الفريق، المخاطر | اجتياز |
| **G4 المنافع** | تحقق المنافع ← مغلقة | الاستلام، الجودة، قياس المنافع، الدروس | اجتياز |

كل بوابة لها **قائمة تحقق معيارية** (`js/domain/stage-gates.js`) تُفتح على المبادرة
وتُنجز بنودها قبل العبور، وكل قرار يتطلب **مسوّغات مكتوبة** ويُحفظ برقم `MDN-DEC-YYYY-NNNN`.

## معايير المفاضلة (المجموع 100)
| المعيار | الوزن |
|---|---|
| التوافق الاستراتيجي | 25 |
| الأثر المجتمعي | 25 |
| الجدوى الفنية والمالية | 20 |
| جاهزية الشريك | 15 |
| انخفاض المخاطر | 15 |

كل معيار يُقيَّم 1–5. النطاقات: **80+** أولوية قصوى، **65+** مرشحة بقوة،
**50+** مقبولة بشروط، وأقل من 50 دون الحد الأدنى.

## إدارة المنافع
- تُعرَّف المنافع عند G2: عنوان، وحدة قياس، خط أساس، مستهدف، مالك منفعة.
- نسبة التحقق = (المقاس − الأساس) ÷ (المستهدف − الأساس) — تصلح للمؤشرات الصاعدة والهابطة.
- لا تُقفل مبادرة عند G4 إلا بعد قياس المنافع؛ تحقق دون 60٪ يظهر في صحة المبادرة.

## إدارة المخاطر
تعرض = احتمالية (1–4) × أثر (1–4). المستويات: 12+ حرج، 8+ مرتفع، 4+ متوسط.
خطر حرج مفتوح يجعل صحة المبادرة «متعثرة» تلقائيًا.

## صحة المبادرة (RAG)
تجميع آلي (`js/domain/initiative-health.js`): تأخر الجدول مقابل الزمن المنقضي،
الصرف مقابل الإنجاز، أعلى تعرض مخاطر مفتوح، وتحقق المنافع — مع أسباب مكتوبة لكل تقييم.

## أدوار الحوكمة
- **مكتب إدارة المبادرات**: يدير الدورة كاملة ويطرح الاحتياجات.
- **لجنة المراجعة**: توصيات مكتوبة عند البوابات (شاشة المراجعات).
- **القرار**: يسجَّل باسم متخذه مع المسوغات ويُبث إشعار به.
- **سجل التدقيق**: كل تعديل موثق تلقائيًا (من، متى، ماذا).
