# دليل مدير النظام — منصة المبادرات

## البنية التقنية
- تطبيق ويب ثابت (HTML/CSS/JS ES Modules) **بلا خطوة بناء وبلا اعتمادات npm**.
- التخزين: IndexedDB باسم `madinah-initiatives-platform-db` (الإصدار 1، 23 مخزنًا).
- Service Worker بنطاق `./` وأسماء Cache ببادئة `madinah-initiatives-platform-`.
- مفاتيح LocalStorage ببادئة `madinahInitiativesPlatform:`.
- قنوات BroadcastChannel: `madinah-initiatives-platform-{events,settings,notifications}`.

## التشغيل
```bash
cd initiatives-platform
npm run serve          # خادم تطوير على 8210
# أو أي خادم ملفات ثابت — python -m http.server 8000
```

## الفحوص
| الأمر | الوظيفة |
|---|---|
| `npm run lint` | صياغة كل ملفات JS كوحدات ES |
| `npm test` | اختبارات الوحدة والتكامل |
| `npm run test:e2e` | خادم حقيقي + فحص كل الصفحات والأصول |
| `npm run check` | فحوص الاستقلالية (قاعدة/SW/مفاتيح/مسارات) |
| `npm run validate:links` | لا روابط مكسورة ولا مسارات من جذر النطاق |

## إدارة البيانات
- **البذور**: تُزرع البيانات التجريبية تلقائيًا عند أول تشغيل إذا كانت القاعدة فارغة
  (`js/services/import-service.js`). علم الزرع في مخزن `settings` بسجل `seed-status`.
- **النسخ الاحتياطي**: من الإعدادات — ملف `madinah-initiatives-backup-YYYY-MM-DD.json`
  يشمل بيانات هذه المنصة فقط مع `schemaVersion` و`applicationName` و`checksum`.
- **الاستعادة**: تفحص الاسم والإصدار والمجموع قبل أي كتابة، مع خيار استبدال كامل أو دمج.
- **سجل التدقيق**: كل إنشاء/تحديث/حذف يسجَّل تلقائيًا. نقّه من الإعدادات (يبقي آخر 500).

## ترقية مخطط القاعدة
1. ارفع `DB_VERSION` في `js/core/constants.js`.
2. أضف مدخلًا جديدًا في `js/data/migrations.js` بالإصدار الجديد — **لا تعدّل ترحيلات سابقة**.
3. ارفع `BACKUP_SCHEMA_VERSION` في `backup-service.js` إن تغيّر شكل السجلات، وعالج التوافق.

## الأدوار والصلاحيات
مصفوفة الأدوار في `js/core/permissions.js` — أفعال بصيغة `مورد.فعل`.
نسخة العرض بلا مصادقة: الدور يُبدَّل من الإعدادات ويحدد الأزرار الظاهرة فقط.
أي نشر فعلي يتطلب مصادقة حقيقية (انظر خيار Supabase في `supabase/README.md`).

## الإعدادات المحلية
`js/config.local.js` (منسوخ من `config.example.js`) خارج المستودع عبر `.gitignore` —
هذا هو المكان الوحيد لمفاتيح Supabase.

## استكشاف الأخطاء
- **صفحة بيضاء**: افتح Console — غالبًا فتح عبر `file://` (الوحدات تتطلب خادمًا).
- **بيانات لا تتحدث بين تبويبين**: تحقق من دعم BroadcastChannel وأن التبويبين من نفس الأصل.
- **SW قديم**: DevTools ‏> Application ‏> Service Workers ‏> Update/Unregister،
  أو ارفع أرقام إصدارات Cache في `service-worker.js`.
