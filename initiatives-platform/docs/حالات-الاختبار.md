# حالات الاختبار

## الاختبارات الآلية

### الوحدة — `tests/unit` (57 اختبارًا)
| الملف | يغطي |
|---|---|
| scoring.test.mjs | حدود الدرجة (20–100)، القص 1–5، النطاقات، التوصيات |
| workflow.test.mjs | الانتقالات المسموحة/الممنوعة حسب الدور، بوابات الانتقال، ترتيب الحالات |
| stage-gates.test.mjs | قوالب القوائم، بناء القائمة، الجاهزية 100٪، البوابة القادمة، مسار البوابات |
| benefits.test.mjs | نسبة التحقق (صاعد/هابط)، الحالات، ملخص المحفظة، سقف 100٪ |
| risks.test.mjs | التعرض، المستويات، أعلى مفتوح، مصفوفة 4×4، القص |
| validation.test.mjs | القواعد الأساسية + تحقق نماذج المبادرة/الاحتياج/الشريك |
| utils.test.mjs | المعرفات الرسمية، الحساب، الفرز، checksum، التعقيم، التواريخ |
| initiative-health.test.mjs | RAG: سليمة/متابعة/متعثرة بأسبابها |

### التكامل — `tests/integration` (21 اختبارًا)
| الملف | يغطي |
|---|---|
| backup.test.mjs | قبول النسخة السليمة، رفض اسم تطبيق آخر، إصدار غير مدعوم، عبث بالمجموع، مخازن دخيلة |
| export-permissions.test.mjs | CSV (BOM/اقتباسات)، تعقيم جداول الطباعة، مصفوفة الصلاحيات، ترحيلات القاعدة |
| demo-data.test.mjs | صلاحية كل البيانات التجريبية ومراجعها المتبادلة وتغطية دورة الحياة |

### E2E — `tests/e2e` (18 اختبارًا)
خادم حقيقي (`tools/serve.mjs`) ثم: كل صفحة 200 بعلامتها، عربية RTL،
كل أصل مُشار إليه يُحمَّل، أنواع المحتوى، manifest نسبي، 404 عربية،
لا مسارات جذر نطاق، استيراد وحدات النطاق فعليًا.
