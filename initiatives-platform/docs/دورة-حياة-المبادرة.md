# دورة حياة المبادرة

## الحالات

| الحالة | المعرف | الوصف |
|---|---|---|
| مسودة | `draft` | لم تُقدَّم بعد (داخلية) |
| مقدَّمة | `submitted` | وصلت عبر البوابة أو الشريك أو داخليًا |
| قيد الفرز | `screening` | أمام بوابة G0 |
| قيد الدراسة | `study` | أمام بوابة G1 — تُستكمل الدرجات |
| قيد الاعتماد | `approval` | أمام بوابة G2 — الشراكة والمنافع |
| جاهزية التنفيذ | `readiness` | أمام بوابة G3 |
| قيد التنفيذ | `execution` | معالم ومنصرف وجودة |
| تحقق المنافع | `benefits` | اكتمل التنفيذ — قياس قبل G4 |
| مغلقة | `closed` | اجتازت G4 |
| معتذَر عنها | `rejected` | قرار اعتذار مسبب عند G0 أو G1 |
| معلَّقة | `onHold` | تعليق مؤقت عند G2 |

## مخطط الانتقالات

```
مسودة ──تقديم──▶ مقدَّمة ──بدء الفرز──▶ قيد الفرز
قيد الفرز ──G0 اجتياز──▶ قيد الدراسة        قيد الفرز ──G0 اعتذار──▶ معتذَر عنها
قيد الدراسة ──G1 اجتياز──▶ قيد الاعتماد      قيد الدراسة ──G1 اعتذار──▶ معتذَر عنها
قيد الاعتماد ──G2 اجتياز──▶ جاهزية التنفيذ   قيد الاعتماد ──G2 تعليق──▶ معلَّقة
معلَّقة ──إعادة تفعيل──▶ قيد الاعتماد
جاهزية التنفيذ ──G3 اجتياز──▶ قيد التنفيذ
قيد التنفيذ ──اكتمال──▶ تحقق المنافع ──G4 اجتياز──▶ مغلقة
```

المصدر البرمجي الوحيد للانتقالات: `js/domain/workflow.js` (`TRANSITIONS`).
أي انتقال موسوم ببوابة يفتح نافذة قرار إلزامية المسوغات، ويُسجَّل في:
1. `statusHistory` داخل سجل المبادرة (من، إلى، متى، من نفّذ، رقم القرار).
2. مخزن `decisions` بسجل قرار مستقل.
3. سجل التدقيق `auditLogs`.

## من يملك ماذا؟
انظر `مصفوفة-الصلاحيات.md` — خلاصة الانتقالات:
- **التقديم**: عام (البوابة) أو من يملك `initiatives.create`.
- **بدء الفرز والاكتمال وإعادة التفعيل**: `initiatives.transition` (مكتب المبادرات فأعلى).
- **قرارات البوابات كلها**: `decisions.create` (مكتب المبادرات ومدير النظام).

## المعرفات الرسمية
- مبادرة: `MDN-INIT-YYYY-NNNN` — احتياج: `MDN-NEED-YYYY-NNNN`
- شريك: `MDN-PRT-YYYY-NNNN` — قرار: `MDN-DEC-YYYY-NNNN`

التسلسل يُحسب لكل سنة على حدة من أعلى رقم موجود (`js/data/repositories.js`).
