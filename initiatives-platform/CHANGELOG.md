# سجل التغييرات — منصة المبادرات

## 1.0.0 — 2026-08-30

الإصدار الأول الكامل.

### أضيف
- البوابة العامة: فرص مطروحة، حملات، رحلة البوابات، مؤشرات حية من قاعدة البيانات.
- معالج تقديم مبادرة من 4 خطوات برقم متابعة رسمي وصفحة تتبع عامة.
- بوابة الشركاء بعرض مبادرات كل جهة ومنافعها.
- تطبيق إدارة بموجّه Hash: لوحة متابعة، مبادرات (سجل + تفاصيل + انتقالات بقرارات مسببة)،
  احتياجات، شركاء، مراجعات، قرارات، تنفيذ، منافع، مخاطر (مصفوفة 4×4)، جودة، خريطة SVG، تقارير، إعدادات.
- حوكمة Stage-Gate بخمس بوابات وقوائم تحقق معيارية وجاهزية عبور.
- نموذج مفاضلة موزون (5 معايير / 100) ومؤشر صحة RAG مجمع.
- قاعدة IndexedDB مستقلة `madinah-initiatives-platform-db` (إصدار 1) ببنية ترحيلات و23 مخزنًا.
- مزوّد Supabase اختياري (REST) بنفس عقد المزود المحلي + ملفات SQL (schema/rls/seed).
- Service Worker بنطاق `./` وبادئة Cache مستقلة وصفحة عدم اتصال.
- نسخ احتياطي/استعادة بمخطط موثّق (schemaVersion، applicationName، checksum).
- سجل تدقيق وإشعارات عبر قنوات BroadcastChannel مستقلة.
- تقارير طباعة A4 وتصدير CSV (UTF-8 BOM).
- 78 اختبار وحدة وتكامل + 18 اختبار E2E + أدوات lint/check/validate-links بلا اعتمادات.
- وثائق عربية: دليل المستخدم، مدير النظام، الحوكمة، النشر، قاموس البيانات،
  مصفوفة الصلاحيات، دورة حياة المبادرة، حالات الاختبار.
